# 元素 ↔ 口味 ↔ 菜品 对照表

这张表是「元素共鸣点单」的全部规则来源。改映射只需要改这里 + `scripts/elemental.mjs`
里的 `ELEMENTS` 常量，两边必须同步。

## 七个元素

| 元素 | key | 槽位 | 口味 | 映射逻辑 | 匹配关键词（优先级从高到低） |
|---|---|---|---|---|---|
| 火 | `pyro` | 主菜 | 热辣 | 辣味/炸物承担主要饱腹感，是队伍的"输出核心" | 麦辣、香辣、辣味、辣、鸡腿堡、鸡翅、鸡块、板烧、烤、鸡 |
| 水 | `hydro` | 饮品 | 解渴 | 汽水茶饮负责"回血"，饭桌上的水分补给 | 可乐、雪碧、饮品、汽水、果汁、橙汁、红茶、柠檬、矿泉水、茶、饮 |
| 风 | `anemo` | 轻食 | 轻盈 | 沙拉卷类低负担，风元素的"轻功"意象 | 沙拉、鲜蔬、蔬菜、卷、轻、鸡排、鸡胸、玉米杯 |
| 雷 | `electro` | 充能 | 提神 | 咖啡因=元素充能，午后续航 | 咖啡、拿铁、美式、卡布、摩卡、能量、提神 |
| 草 | `dendro` | 轻食 | 清爽 | 蔬果类，生机勃勃 | 沙拉、蔬、玉米、苹果、鲜、青 |
| 冰 | `cryo` | 甜品 | 甜冰 | 甜品是新地/麦旋风/甜筒的天下 | 冰淇淋、新地、麦旋风、圣代、甜筒、派、冰、甜 |
| 岩 | `geo` | 主菜 | 扎实 | 牛肉/碳水，磐岩一样扛饿 | 巨无霸、安格斯、牛肉、双吉、吉士、堡、薯条、薯 |

> **关键词是"包含匹配"**，不是精确匹配。`麦辣鸡腿堡` 同时命中 `麦辣`(权重最高) 与 `鸡`，
> 取累计分最高的元素。所以关键词顺序即权重，越靠前越权威。

## 元素反应（双元素搭配）

| 组合 | 反应 | 说明 |
|---|---|---|
| 火 + 水 | 蒸发 | 辣味主菜 + 冰饮，伤害翻倍 |
| 火 + 雷 | 超载 | 辣味主菜 + 咖啡，午后的炸裂组合 |
| 火 + 冰 | 融化 | 辣味主菜 + 冰甜品，冷热交替 |
| 水 + 冰 | 冻结 | 冰饮 + 冰甜品，全冰阵型（注意胃） |
| 雷 + 冰 | 超导 | 咖啡 + 冰甜品，超标充能 |
| 草 + 水 | 绽放 | 沙拉 + 冰饮，健康向配队 |
| 风 + 火 | 扩散 | 轻食 + 辣味主菜，负担小伤害高 |
| 岩 + 岩 | 结晶 | 双主食，岩队专属碳水阵型 |
| 其余 | 元素共鸣 | 非主流配队，但吃得开心最重要 |

不在表里的组合不会报错，会回落到"元素共鸣"兜底文案。

## 组队 → 点单的结构规则

```
1. 槽位排序：提供「主菜」槽位的元素提到最前，保证方案里一定有一道主食
2. 逐元素取一个菜品：同元素候选按「契合分 ↓，价格 ↑」排序，取第一个没用过的
3. 补位：不足 maxItems（默认 4）时，按 冰 → 水 → 雷 的顺序补甜品/饮品
4. 预算裁剪：超预算时，先砍补位项，再砍最贵的非主菜；主菜永远保留
```

## 怎么扩展

**加菜品关键词**：直接在 `ELEMENTS[key].keywords` 数组里插入，注意位置即权重。

**加元素**：`ELEMENTS` 里加一项 + `ELEMENT_ORDER` 加 key + 本表加一行。
`slot` 只能取已有的槽位名，否则组队排序会退化但不会崩。

**换成别的主题**（比如不要二次元、改成都市民口味标签）：
只需要重写 `ELEMENTS` 的 `zh / full / taste / motto / keywords`，
`elemental.mjs` 其余代码与 `artifact.mjs` 完全不用动 ——
元素只是一个"分类标签"，优化引擎不关心它叫什么。
